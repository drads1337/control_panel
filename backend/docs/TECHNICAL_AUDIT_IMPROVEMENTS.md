# План улучшений на основе технического аудита

## Статус: Pre-production → Production-Ready

### Выявленные проблемы

#### 1. Переходный код (Facades и Deprecation Monitors)

**Проблема:**
- `KeyServiceFacade` и `UserManagementServiceFacade` используются для обратной совместимости
- `deprecation_monitor.py` отслеживает использование устаревших функций
- Это указывает на незавершенный рефакторинг

**Влияние:**
- Дополнительный слой абстракции усложняет поддержку
- Дублирование логики между фасадами и специализированными сервисами
- Затрудняет понимание актуального API

**Решение:**
1. Постепенная миграция кода с фасадов на специализированные сервисы
2. Удаление фасадов после полной миграции
3. Удаление deprecation_monitor после завершения миграции

#### 2. Зависимость от глобального состояния (flask.g)

**Проблема:**
- 219+ использований `g.current_user`, `g.project_id` по всему коду
- Неявные зависимости усложняют тестирование
- Затрудняет понимание потока данных

**Влияние:**
- Сложность unit-тестирования (требуется Flask request context)
- Неявные зависимости между компонентами
- Потенциальные проблемы с конкурентностью в async-контекстах

**Решение:**
1. Постепенная миграция к явной передаче параметров
2. Использование dependency injection вместо глобального состояния
3. Сохранение `flask.g` только для middleware и query isolation
