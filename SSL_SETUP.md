# Настройка SSL сертификатов

## Let's Encrypt (Рекомендуется для production)

### Получение сертификатов

1. Убедитесь, что домен `ovrin.xyz` указывает на ваш сервер (A-запись)
2. Убедитесь, что порты 80 и 443 открыты
3. Запустите контейнеры (если еще не запущены):
   ```bash
   docker compose up -d nginx
   ```
4. Получите сертификаты:
   ```bash
   ./obtain_ssl_cert.sh your-email@example.com
   ```

Скрипт автоматически:
- Создаст необходимые директории
- Получит сертификаты от Let's Encrypt
- Обновит конфигурацию nginx для использования Let's Encrypt сертификатов
- Перезагрузит nginx

### Обновление сертификатов

Сертификаты Let's Encrypt обновляются автоматически каждые 12 часов через контейнер certbot.

Для ручного обновления:
```bash
./renew_ssl_cert.sh
```

## Самоподписанные сертификаты (Только для разработки)

Самоподписанные сертификаты создаются автоматически скриптами развертывания, если Let's Encrypt сертификаты не найдены.

⚠️ **Внимание**: Самоподписанные сертификаты вызывают предупреждения в браузере и не подходят для production!

## Структура файлов

- `letsencrypt/` - директория с Let's Encrypt сертификатами (игнорируется git)
- `nginx/ssl/` - директория с самоподписанными сертификатами (fallback)

## Проверка сертификатов

После получения Let's Encrypt сертификатов проверьте:

```bash
# Проверка сертификата
openssl x509 -in letsencrypt/live/ovrin.xyz/fullchain.pem -text -noout | grep -A 2 "Subject:"

# Проверка в браузере
# Откройте https://ovrin.xyz и проверьте, что нет предупреждений о сертификате
```

## Устранение проблем

### Ошибка: "Failed to obtain certificate"

- Убедитесь, что домен указывает на ваш сервер
- Убедитесь, что порт 80 открыт (нужен для ACME challenge)
- Проверьте логи: `docker compose logs certbot`

### Nginx не запускается

- Убедитесь, что самоподписанные сертификаты созданы (если Let's Encrypt не используется)
- Проверьте конфигурацию: `docker compose exec nginx nginx -t`

### Предупреждение о SSL stapling

Это нормально для самоподписанных сертификатов. После перехода на Let's Encrypt предупреждение исчезнет.
